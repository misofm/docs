The [Miso Music Protocol](https://github.com/misofm/music-protocol) keeps the core small: a composition identifies a written work, a recording points to a composition, and a release contains an ordered list of recordings. Each work has a fixed-supply share type. Licensing, royalties, credits, titles, artwork, and sales belong to separate packages.
