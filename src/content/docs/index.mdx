Miso's [music protocol](https://github.com/misofm/music-protocol) keeps the core small: a composition identifies a written work, a recording points to a composition, and a release contains an ordered list of recordings. Each work has a fixed-supply share coin. Licensing, royalties, credits, titles, artwork, and sales belong to separate packages.

These pages describe the current source model as of October 2026. Package source, pinned dependencies, and published on-chain generations can differ. Before building a transaction against a network, use the package IDs and APIs for that deployed generation.
